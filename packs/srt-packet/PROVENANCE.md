## Licence

The draft is an IETF document: "Copyright (c) 2021 IETF Trust and the persons identified as the document
authors. All rights reserved." It is subject to BCP 78 and the IETF Trust's Legal Provisions Relating to
IETF Documents. The pack keeps the default Apache-2.0 label. The draft has expired as a draft; it remains the
published description of SRT that Haivision's open-source implementation follows.

This pack restates the layouts (field order, sizes, codes) in its own words; no text, figure, table or
code of the sources is copied. The vectors are packets built by `tools/gen/media-vectors.py` from values
chosen there; their expected bytes are derived there, without an engine.
