# Provenance of the schema sources

Pack `openxc-vehicle-message` and module `openxc` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/protobuf-4-run.sh`) with the envelope `openxc.VehicleMessage`. The schema files are not kept in this
repository.

## What this repository holds from the file

The generator is run with `--no-comments`. The pack, its module `openxc`, the names file
`tools/gen/names/openxc-vehicle-message.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from the file: no comment
and no line of a file. The values in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-4-vectors.py`).
