# Pack: asterix-cat007

ASTERIX Category 007, Transmission of Directed Interrogation Messages, edition 1.12 (2024-07-01): one data block holding one record.
Public. Generated by `tools/gen/asterix2pack.py` from the machine-readable definition of the
category in `github.com/zoranbosnjak/asterix-specs` (BSD-3-Clause), file `specs/cat007/cats/cat1.12/definition.json` at commit
`64e9ffba964b92a1af3157bc6bdf7852a63bf700`. The category itself is specified by EUROCONTROL. I/O is hex text.
Needs engine version 0.20 (`switch`).

Uses the modules `core` and `cat007` (`model/cat007.def`, generated with the pack).

## Layout

`layout sequential`, `bit_order msb`. One kind, `record`.

| Part | Lines | Meaning |
|---|---|---|
| CAT, one octet | `when 8 7` | selects the kind; another category is `no-kind` |
| LEN, two octets | `length 16 whole` | the block length in octets, CAT and LEN included; written on encode, and on decode input beyond it is not read |
| FSPEC | `presence f fx` | bit n is FRN n of the UAP |
| common items | one `if f.<frn>` block per FRN up to 3, I007/410 | the same items in every UAP |
| `switch cat007.i410` | one `case` per UAP after the first, and `else` | the items of the UAP that I007/410 selects, one `if f.<frn>` block per mapped FRN |

A data block that holds more than one record: the first record is read and the rest of the block is not.

### The UAPs

The definition gives the category 2 UAPs and names I007/410 as the field whose value says which one
a record follows. Every UAP holds the same items up to FRN 3, so those are written once, before a
`switch` on `cat007.i410` (engine-spec 0.20):

| UAP | Arm | I007/410 | FRNs | mapped |
|---|---|---|---|---|
| `downlink` | `else` | 0, 1, 2, 3, 4, any value no `case` lists, or the item absent | 35 | 33 |
| `uplink` | `case 5,6,7,8` | 5, 6, 7, 8 | 21 | 15 |

- **Decode.** The value read from I007/410 picks the case; a value the definition gives no UAP for reads the `else` lines. A record without I007/410 leaves the key absent,
  and the `else` lines are read: UAP `downlink`, which is also the layout the earlier one-UAP pack read.
  The definition names no UAP for a record without the item or with a value it does not list; reading the first is this pack's choice.
- **FSPEC bits.** Only the `if` lines of the case read name FSPEC bits, so a bit that only another UAP
  maps is `malformed-wire` in a record of this UAP.
- **Encode.** The case is the one decode would pick from what was written: the value of `cat007.i410`,
  zero when the item is written without it, and `else` when the item is not written at all. Keys of
  items that only another UAP holds are not written.
- **One kind.** The UAP is not a kind: `@kind` is `record` for every UAP, and the decoded `cat007.i410`
  tells them apart. An item two UAPs share has one set of keys, whichever FRN it has in each.

Mapped without content: SPF, Special Purpose Field (FRN 34 in `downlink` and 20 in `uplink`), REF, Reserved Expansion Field (FRN 35 in `downlink` and 21 in `uplink`). Decode reads the length octet and passes over the content; no key holds it,
so encode never writes the item, and a same-format round trip of a record that holds one returns the
record without it.

A shared key is bound only where the text of the definition and the unit leave no doubt, and only on an

| `speed_ms` | I007/200/GSP | `field speed_ms … uscale:463/4096`: factor 1852 folded into the scale; the field has no raw key | I007/200 "Calculated Track Velocity in Polar Co-ordinates", subitem GSP "Calculated Groundspeed"; LSB 1/16384 NM/s |
| `cat007.i140` (the module's own key) | I007/140 | `derive cat007.i140 day_seconds time_ms` in the module: on a conversion from another format the time of day follows from `time_ms` | I007/140 "Time of Day", definition: "Absolute time stamping expressed as Co-ordinated Universal Time (UTC)."; note: "Notes: 1. The time of day value is reset to 0 each day at midnight. 2. Every radar station using ASTERIX should be equipped with at least one synchronised time source" |

Where a field has a shared key and a raw key, the shared key is on the `field` line and the raw key on
the `also` line. Decode fills both. Encode writes the earliest key that is present (ruling 13 of 0.8), so
the shared key wins: a consumer that changes `lat` sees the change on the wire, and a change made only
to the raw key is not written (ruling 16 of 0.5 asks for this order).

Where the unit of the definition is not the unit of the shared key, the conversion factor is part of
the scale (one foot is 381/1250 m, one NM/s is 1852 m/s, one knot is 1852/3600 m/s), the field holds
the shared key alone, and `model/cat007.def` has no raw key for it: an `also` line shares the transform of
its field, so one field cannot hold feet in one key and metres in another.

`callsign` stands in I007/240, which only UAP `downlink` holds: it is read and written only in that case. An entity
converted from another format reaches it only when it also holds `cat007.i410` with that UAP's value.

Not bound, on purpose: a position, height or speed inside a compound or repetitive item (it describes
something other than the reported target's own state, or one of several); a flight level or barometric
altitude (`hae` is geometric); a heading, or a track angle whose reference the definition does not state
(`course` is degrees true); a Cartesian velocity or position in a local system whose axes the definition
does not state; a polar position relative to a sensor; a time item where the category has several.

## Converting to this pack

The kind has no `requires` line: the definition does not mark items as mandatory, so encode writes the
items whose keys the entity holds. A field of a written item whose key is absent is written as zero.
The UAP follows `cat007.i410` as written (section "The UAPs"): an entity without it is written with UAP
`downlink`, and keys of items only another UAP holds are left out.
Keys of `cat007` that another format does not carry (SAC and SIC, for example) are given as context.
