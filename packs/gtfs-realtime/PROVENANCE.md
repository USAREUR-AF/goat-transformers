## What this repository holds from that file

The generator is run with `--no-comments`. The packs, the module `gtfsrt`, the names files
`tools/gen/names/gtfs-realtime.json` and `tools/gen/names/gtfs-realtime-entity.json` and the
generated vectors record field numbers, message and field names, and field types, and nothing
else from the file. The five bindings of `gtfs-realtime-entity` rest on the units and meanings
the file's comments state; `pack.md` restates them in this repository's own words. The values
in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-public-vectors.py`).
