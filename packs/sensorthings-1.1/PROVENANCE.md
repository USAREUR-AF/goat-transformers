# Provenance: sensorthings-1.1 pack

SPDX licence: Apache-2.0

Read on 2026-11-20. No source file is copied into this tree. The pack and the module
`sensorthings` (shared with the other SensorThings pack) hold member names and value forms
from the standard's entity tables; descriptions are in our own words. Every message in the
vectors is written for this repository.
