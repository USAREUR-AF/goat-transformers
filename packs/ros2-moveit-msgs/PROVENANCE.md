- common_interfaces and rcl_interfaces: each package directory of common_interfaces
  holds a `LICENSE` file, and rcl_interfaces holds one at its root, that begins
  "Apache License / Version 2.0, January 2004" and is the full text of the Apache
  License, Version 2.0. Each package's `package.xml` states
  `<license>Apache License 2.0</license>`. The .msg files carry no header.
- moveit_msgs: `LICENSE` is the three-clause BSD text with no copyright line ("Redistribution and use in source and binary forms, with or without modification, are permitted provided that ..."); `package.xml` states `<license>BSD</license>`.
- octomap_msgs: the repository has no LICENSE file. `package.xml` states `<license>BSD</license>`, and `include/octomap_msgs/conversions.h` of the same package carries the BSD text (listed). The .msg files carry no header.
- object_recognition_msgs: the repository has no LICENSE file and no file carries a licence text. `package.xml` states `<license>BSD</license>`, the declared licence of the package; it is read here because moveit_msgs refers to its messages.
- rosbridge_suite: `LICENSE` at the root begins "BSD 3-Clause License" and
  "Copyright (c) The Rosbridge Authors"; `message_conversion.py` carries the header
  "Software License Agreement (BSD License)", "Copyright (c) 2012, Willow Garage, Inc."
  The protocol text `ROSBRIDGE_PROTOCOL.md` (rosbridge v2.1.0 Protocol
  Specification) is in the same repository under that license.
