## How a schema is read

Each member of a scalar type is a `field` line; members of nested objects have dotted paths.
An array is a `group` (engine-spec 0.7): items that are objects are walked as a message is,
with paths relative to the item; items of a scalar type are one `.` line. `allOf`, `oneOf`
and `anyOf` contribute the members of every branch, merged by name; `null` among the
types means the member may be absent. Types: string `string`, integer `int`, number
`float` (`int` when the schema states `multipleOf: 1`), boolean `bool`. A `date-time`
string is kept as text in its raw key, so it round-trips as written.

Residue (engine-spec 0.5): a scalar member no line maps, at any depth of nested objects, is
carried back; arrays no group maps, and anything inside them, are not.
