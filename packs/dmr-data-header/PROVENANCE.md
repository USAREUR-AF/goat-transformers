carries the default Apache-2.0 label. ETSI TS 102 361 was not used.

This pack restates the layout (octet and bit positions by data packet format) in its own words; no code
or comment is copied. The vectors are built by `tools/gen/hamdig-vectors.py` from values chosen there;
their expected bytes are derived there, without an engine.
