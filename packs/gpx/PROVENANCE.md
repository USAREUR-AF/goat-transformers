module `gpx` hold element and attribute names, types and ranges taken from the
schema; descriptions are in our own words. The vectors are messages written
for this repository.

## License

The schema file carries no license or copyright statement. The publisher's
overview page states:

> GPX is an open standard.

and

> All text on this Web page is in the public domain.

The schema's own header says, of the format, that all coordinates are relative
to the WGS84 datum and all measurements are in metric units (paraphrased).
This pack uses only names, types and ranges of the schema, which are facts of
the format, and no text of it.
