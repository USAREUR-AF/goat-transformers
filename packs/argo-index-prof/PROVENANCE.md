# Provenance of the argo-index-prof pack

SPDX licence: Apache-2.0

Written by hand from the column header line of the Argo GDAC profile directory file; the vectors
by `tools/gen/ocean-text-vectors.py`. The file is not kept in this repository. Read on 2026-11-21.

## Source

| | |
|---|---|
| Document | Argo Global Data Assembly Center profile directory file `ar_index_global_prof.txt`, format version 2.0 (stated in its comment lines) |
| Publisher | International Argo Program; GDAC node Coriolis (Ifremer) |
| Address | https://data-argo.ifremer.fr/ar_index_global_prof.txt (the first lines read, 2026-11-21) |

## Licence

The Argo Program states that "Argo data are freely available without restriction"
(https://argo.ucsd.edu/data/acknowledging-argo/, read 2026-11-21). The pack restates the column
names of the directory file's header line and labels them with the project's licence,
Apache-2.0 (the default annotation). Users of Argo data are asked to acknowledge it: These data
were collected and made freely available by the International Argo Program and the national
programs that contribute to it (https://argo.ucsd.edu, https://www.ocean-ops.org); the Argo
Program is part of the Global Ocean Observing System. Argo DOI: https://doi.org/10.17882/42182.
