## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `gzmsgsparamv`, the names file
`tools/gen/names/gz-msgs-param-v.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file. The values in the vectors are made by the generator.
