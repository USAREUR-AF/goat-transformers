## The message

`wire bits`, `bit_order lsb`, `word_bytes 1`; hex text. One SBP frame from the
preamble through the payload; all numbers are little-endian:

| Bytes | Content | In the pack |
|---|---|---|
| 0 | preamble 0x55 | common `when` |
| 1-2 | message type | per-kind `when` |
| 3-4 | sender id | `sbp.sender` (module `sbp`, shared by every SBP pack) |
| 5 | payload length in bytes | per-kind `when` = the message's fixed size |
| 6 … | payload | the kind's `field` lines, at their offsets |
| after the payload | CRC-16 (2 bytes) | not mapped |

The message is the frame without its CRC, in both directions: decode takes the
preamble, header and payload, and encode writes them. A framer adds the CRC
before sending and checks it on receipt: CRC-16 CCITT (polynomial 0x1021,
initial value 0) over the header and the payload, preamble excluded, written
little-endian after the payload. That is the item "Layered wires and framing"
of `docs/roadmap.md`. The fields of a payload follow one another with no
padding.

Keys are `sbpsystem.<message>_<field path>` in lower case, the message name without
`MSG_`. Bit fields inside an integer (a flags byte) are carried as the whole
integer.

### Core keys

No key is bound to a `core` or `track` key: no message of this package states
a position, velocity or course with the meaning and unit of a shared key.

### `requires`

Each kind requires up to 3 of its own keys, so an entity from another format
selects a kind only when it holds them.
