# Pack: arsdk-controller-info

The commands and events of the Parrot ARSDK feature `controller_info` (id 140), one kind
per command. Public. Generated by `tools/gen/arsdk2pack.py` from `xml/controller_info.xml` of
arsdk-xml (BSD-3-Clause, commit `2299c689be5951fa2104793e0154b0b5b1896c03`, sha256 `6c642125d90f9d271ea48c3a33aea57a60b0c73f936c8010b57f8f4e35e3785b`).

## Message convention

A message is one ARSDK command as libARCommands encodes it: the feature id (8 bits),
the class id (8 bits; 0 for a feature without classes), the command id (16 bits), then the
arguments in schema order, little-endian. An enum is 32 bits, a bitfield is its base
integer, `float` and `double` are IEEE-754. The network framing around a command
(the ARNetworkAL frame: type, buffer id, sequence number and size) is not part of the
message; a caller removes it before `decode` and adds it after `encode`. The pack
selects the kind by the header (`when`); a command carries no length of its own, and
input beyond the last argument is not read.

Commands whose type is `LIST_ITEM` or `MAP_ITEM` are one item of a list each; each
item is one message, and the pack reads it as any other command.

## Shared keys

| Kind | Argument | Key | Transform | Absent when |
|---|---|---|---|---|
| `gps` | `latitude` | `lat` | `f64` |  |
| `gps` | `longitude` | `lon` | `f64` |  |
| `gps` | `north_speed` | `track.vel_north_ms` | `f32` |  |
| `gps` | `east_speed` | `track.vel_east_ms` | `f32` |  |
| `gps` | `down_speed` | `track.vel_up_ms` | `f32scale:-1` |  |
| `gps_v2` | `latitude` | `lat` | `f64` |  |
| `gps_v2` | `longitude` | `lon` | `f64` |  |
| `gps_v2` | `wgs84_altitude` | `hae` | `f32` |  |
| `gps_v2` | `north_velocity` | `track.vel_north_ms` | `f32` |  |
| `gps_v2` | `east_velocity` | `track.vel_east_ms` | `f32` |  |
| `gps_v2` | `up_velocity` | `track.vel_up_ms` | `f32` |  |

- `gps`: the controller's GPS: latitude and longitude in degrees; north and east speed in metres per second; the down speed in metres per second, positive downwards, so `vel_up` is its negative (`f32scale:-1`); the altitude is above sea level, a raw key.
- `gps_v2`: the controller's GPS: latitude and longitude in degrees, the altitude above the WGS 84 ellipsoid in metres (`hae`; the altitude above mean sea level is a raw key), north, east and up velocity in metres per second, up positive.

The schema gives latitude and longitude in degrees from a GPS receiver but, apart from `controller_info` `gps_v2` (whose other altitude is above the WGS 84 ellipsoid), names no datum. The binding to `lat` and `lon`, which are WGS 84, rests on the reading that a GPS receiver reports WGS 84; a reviewer who does not accept it removes the entries of `BIND` in `tools/gen/arsdk2pack.py` and runs it again, and the raw keys, which stand on the same bits in every case, remain.

Other commands carry a latitude and longitude that are not the position of the reporting thing (a move target, a point of interest, a home, take-off or return location, a geofence centre, a followed target's trajectory): they are raw keys.

An entity from another format encodes as `gps_v2` (it requires `lat` and `lon`); every other kind requires the raw `arsdkcontrollerinfo.feature_id`, which only a decoded ARSDK command holds.
