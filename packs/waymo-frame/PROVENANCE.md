# Provenance of the schema sources

Pack `waymo-frame` and module `waymoframe` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/protobuf-4-run.sh`) with the envelope `waymo.open_dataset.Frame`. The schema files are not kept in this
repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `waymoframe`, the names file
`tools/gen/names/waymo-frame.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no comment
and no line of a file. The values in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-4-vectors.py`).
