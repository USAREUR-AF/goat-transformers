Status: Built. Generated and checked by the generator's own serializer and codec.

No RTCM document was read: the definitions are pyrtcm's BSD-licensed
restatement, read as Python syntax trees.

## The message

`wire bits`, `layout sequential`, `bit_order msb`; hex text. The message is the
body of one RTCM 3 frame: what follows the frame header (the preamble 0xD3, six
reserved bits and the 10-bit length) and comes before the 24-bit CRC. A framer
adds and checks those (the item "Layered wires and framing" of
`docs/roadmap.md`). The body is read in order, most significant bit first; a
message whose bit count is not a multiple of 8 ends in zero padding bits, as
the frame carries it. The message number (data field DF002, 12 bits) is the
kind's `when`.

## What is mapped

| Data field type | Transform | Model type |
|---|---|---|
| `UINT`, `BIT` | `uint`; with an integer scale `uiscale`, with another `uscale` | int, int, float |
| `INT` (two's complement) | `twos`; `siscale`; `sscale` | int, int, float |
| `INTS` (sign and magnitude) | `smag`; with a scale `smscale` | int, float |
| `CHA` (characters) | `ascii` | string |
| `STR` (one byte of a UTF-8 string in a group) | `uint` | int |

A scale is the resolution the source gives the data field, as an exact
fraction (decimal text where a fraction does not fit 64 bits); the source
states no unit, so the module declares none (`-`). A group repeated by the
field just before it is a `group … count <bits>`: that field is the count and
has no key. A group with a fixed number of repeats is written out, `_01`,
`_02`, … appended. A run of 1-bit flags followed by the parts each flag gates
is a `presence` line and one `if` block per part.

### Core keys

None. The reference station position (messages 1005 and 1006, data fields
DF025 to DF027) is geocentric (ECEF) and the source states no unit for it, so
it stays raw; the 0.16 derives `lat_of_ecef`, `lon_of_ecef` and `hae_of_ecef`
would give a position from it once the unit (metres) is shown by a source.
Ephemeris and time fields stay raw.

### `requires`

Each kind requires up to 3 of its own keys, so an entity from another format
selects a kind only when it holds them.

## Vectors

`vectors/rt-<message>-<kind>.json`: one same-format round trip per kind, the
body written by a serializer in the generator from sample bit patterns; a kind
with a counted group also has one with no items (`-no-items`), and a kind with
gated parts one with some parts absent (`-some-absent`). No conversion vector:
no field binds a core key.
