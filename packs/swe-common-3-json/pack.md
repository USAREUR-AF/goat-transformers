## How a schema is read

Each member of a scalar type is a `field` line; members of nested objects have dotted paths.
An array is a `group` (engine-spec 0.7): items that are objects are walked as a message is,
with paths relative to the item; items of a scalar type are one `.` line. `allOf`, `oneOf`
and `anyOf` contribute the members of every branch, merged by name; `null` among the
types means the member may be absent. Types: string `string`, integer `int`, number
`float` (`int` when the schema states `multipleOf: 1`), boolean `bool`. A `date-time`
string is kept as text in its raw key, so it round-trips as written.

Residue (engine-spec 0.5): a scalar member no line maps, at any depth of nested objects, is
carried back; arrays no group maps, and anything inside them, are not.

Limits of this pack: objects nested deeper than 4 levels (an array counts as a level) are not mapped (SWE Common aggregates (DataRecord, DataArray, DataChoice, Matrix, DataStream) hold components of any type, which hold aggregates again without bound; four levels hold a record of records of simple components, and deeper parts are not mapped). Such a place is in the table under Not mapped;
outside an array its scalars are residue and round-trip, inside an array they are dropped.

## What a message is

One SWE Common 3.0 data component description, or one DataStream description, as the JSON
object the JSON encoding defines. The member `type` names the component (`Quantity`,
`DataRecord`, ...) and selects the kind. These objects describe data (its definition, unit,
constraints and, for a simple component, an optional inline value); they are not reports
about an entity, so no member is bound to a shared key.

## What the pack language leaves out

- **Values whose JSON type varies.** A Quantity `value` and a constraint's `values` may be a
  number or one of the strings `NaN`, `Infinity`, `+Infinity`, `-Infinity`; a `json` line has
  one type. Outside an array such a member is residue and round-trips as written; inside an
  array (constraint values, nil values of a group item) it is not carried.
- **Intervals and ranges.** Constraint `intervals` and the `value` of a range component are
  arrays of two numbers or arrays of arrays: a group item cannot be an array.
- **Encoded values.** A DataArray, Matrix or DataStream `values` member holds the data as an
  array of arrays or a block of text whose layout the `encoding` member states; the language
  has no line for either.
- **Deep aggregates.** See the depth limit below: components inside components are mapped
  to four levels.
