## The message

as 16 bytes in hex text:

| Bytes | Content | In the pack |
|---|---|---|
| 0-3 | CAN identifier, little-endian; bit 31 extended frame, bit 30 remote request, bit 29 error frame | per-kind `when` on the whole word |
| 4 | data length in bytes | per-kind `when` = the DBC message size |
| 5-7 | padding | not mapped |
| 8-15 | data | the kind's `field` lines; a byte no signal uses in the last place is a `const 0` |

The frame carries its identifier, so a kind is chosen by `when` on it. A DBC
writes an extended identifier with bit 31 set, as SocketCAN does; an identifier
above 0x7FF without it is taken as a 29-bit identifier (opendbc writes some that
way) and the `when` holds it with bit 31 set. A data frame has bits 30 and 29
clear, so a remote or error frame matches no kind.
