`tools/gen/waymo-run.sh`) with the envelope `waymo.open_dataset.SegmentationMetrics`. The schema files are not kept in this
repository.

## No dataset content

The recorded data of the Waymo Open Dataset is under the Waymo Open Dataset License Agreement for
non-commercial use, which this repository does not use: nothing of the dataset was downloaded or
read. The pack holds the message schema only, and every value of its vectors is made up by the
generator.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `waymosegmentationmetrics`, the names file
`tools/gen/names/waymo-segmentation-metrics.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file.
