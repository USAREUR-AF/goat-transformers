# Provenance: netex-site-frame pack

Read on 2026-11-19. No source file is copied into this tree. The pack, the module
`netexsite` and the names file hold element and attribute names, types and value ranges
taken from the schema; descriptions are in our own words. The vectors are documents the
generator writes from the schema, with sample values of its own.
