# ardupilot-log-ilb7

ArduPilot DataFlash log message `ILB7`, logged by every vehicle that builds the library, as the payload of one log
record. Generated by `tools/gen/aplog2pack.py` (run by `tools/gen/aplog2pack-run.sh`);
do not edit by hand.

## Message convention

A log record is a 3-byte header (0xA3, 0x95, the type id) and a payload. A message
of this format is the payload, 56 bytes. The type id of `ILB7` is given by an FMT
record of the same log, and the payload holds no value that names the message, so
no `when` line could select it: each message is a format of its own and the caller
names it. The fields follow one another in the order of the format string `QIfffffffffHHf`,
with no padding, little-endian, as the FMT record states them.

## Shared-model keys

None. Every field is a raw key of module `aplog`, holding the value as it is in
the payload (an `e`, `c` or `L` field keeps its integer, before its multiplier).

## Not mapped, and why

| What | Why |
|---|---|
| The 3-byte record header | it belongs to the log, not the message; the type id differs per log |
| Units and multipliers | they are stated in the key meanings of `model/aplog.def`; the raw keys keep the wire integer, as DataFlash readers before scaling do |
| Bytes of a text field after its first NUL | `ascii` removes trailing NULs and refuses other bytes outside 0x20-0x7E (`transform-decode`) |
| NaN and infinite floats | the `f32` and `f64` transforms refuse them on decode |
| FMT, FMTU, UNIT and MULT records | they describe the other records of a log and are not messages of this format |

## Vectors

`vectors/gen-rt.json` is a round trip with every field set: values chosen by the generator,
packed by its own serializer from the format string. Other `gen-*` files are edge and
error cases and conversions to geojson, each with its rule in `source`. 1 vector file(s).

The definition is in `libraries/AP_ExternalAHRS/AP_ExternalAHRS_InertialLabs.cpp`; see `PROVENANCE.md`.
