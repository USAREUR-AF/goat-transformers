# inertialsense-aiding

Inertial Sense IMX/GPX data sets, group `aiding`. Generated by `tools/gen/cstruct2pack.py` from
`tools/gen/cstruct/inertialsense.json` (run by `tools/gen/inertialsense-run.sh`); do not edit by hand.

## Message convention

A message of this format is one ISB (Inertial Sense binary) packet without its trailing
2-byte checksum: the 6-byte packet header of `src/ISComm.h` (`packet_hdr_t`), then the whole
data set the header's id names. The header starts with the preamble 0x49EF (bytes EF 49),
then a flags byte whose low nibble is the packet type (4 for a data packet, 5 for a set-data
packet), the data id (the DID number) and the payload size in bytes. Each DID is a kind,
selected by its id and by a payload size equal to its struct. The checksum after the payload
is the framer's: the ISB parser of the SDK (`is_comm_parse` in `src/ISComm.c`, with
`is_comm_isb_checksum16`) checks and strips it, and writes it when it sends. A packet with
the offset flag (0x20, a partial data set) or the extended-payload flag (0x10) is not a
message of this format; the common `when` on the high nibble refuses it.

| Header field | Bits | Line |
|---|---|---|
| `preamble` | 0-15 | `when` 18927 (common) |
| `flags, packet type (low nibble)` | 16-19 | raw key `inertialsense.isb_packet_type`, default 4 |
| `flags, extended payload and offset bits (high nibble)` | 20-23 | `when` 0 (common) |
| `id` | 24-31 | `when` per kind: the message id |
| `payloadSize` | 32-47 | `when` per kind: the size of the message struct |

The payload is the struct as the compiler lays it out under `#pragma pack(1)`: the
members one after another with no padding, little-endian, as the file header of data_sets.h states for every multi-byte field. A nested struct is
flattened (`a.b`); an array of up to 64 elements is one key per element (`_0`, `_1`,
...); a longer one is a `group` with a fixed count. A `char` array of up to 255 bytes
is `ascii` text.

## Shared-model keys

None. No struct of this group states a WGS 84 position in degrees. Every field is a
raw key of module `inertialsense`.

## Not mapped, and why

| What | Why |
|---|---|
| The 2-byte checksum after the payload | the framer's (see Message convention), not part of the message |
| Partial and extended packets (flags 0x20, 0x10) | the payload starts with an offset or continues in another packet; the common `when` on the flags' high nibble refuses them |
| Packet types other than data | a get-data, ack or stop packet carries another payload; its size differs from the data set's, so no kind's `when` holds |
| Enumerations and bit fields | carried as the integer the struct holds; the pack names no value |
| NaN and infinite floats | the `f32` and `f64` transforms refuse them on decode (`transform-decode`) |
| Bytes of a text field after its first NUL | `ascii` removes trailing NULs and refuses other bytes outside 0x20-0x7E |

## Vectors

`vectors/gen-rt-<kind>.json`: a round trip per kind with every field set, values chosen by
the generator and packed by its own serializer from the layout. `gen-x-*` convert to
geojson, `gen-err-*` are a short message and an id of no kind. 10 vector files.
