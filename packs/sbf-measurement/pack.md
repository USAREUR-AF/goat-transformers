## The message

`wire bits`, `bit_order lsb`, `word_bytes 1`; hex text. One SBF block without
its sync characters (`$@`) and its CRC; every number is little-endian:

| Bytes | Content | In the pack |
|---|---|---|
| 0-1 | block ID: the block number in bits 0-12, the revision in bits 13-15 | per-kind `when` on the number; `sbf.revision` |
| 2-3 | block length in bytes, counting the 8-byte header | per-kind `when` |
| 4 … | body, padded with bytes to a multiple of 4 | the kind's `field` lines; the padding a `const` of 0 |

The message is the block without sync and CRC, in both directions. A framer
adds the two sync characters and the CRC before the ID, and checks them on
receipt: CRC-16 CCITT (polynomial 0x1021, initial value 0) over the ID, the
length and the body. That is the item "Layered wires and framing" of
`docs/roadmap.md`. Because the length counts the sync and CRC too, a message of
this pack is 4 bytes shorter than its length field.

decode ignores them, encode writes zeros.

### Core keys

None. The source states no unit for any field: PVTGeodetic and the blocks like
it carry latitude and longitude as doubles that the definition file marks in a
comment as radians, and a height. Without a unit stated as data the pack binds
nothing; with one, the 0.16 derive `deg` would give `lat` and `lon` in degrees
from radians, and the Cartesian blocks the ECEF derives.

### `requires`

Each kind requires up to 3 of its own keys, so an entity from another format
selects a kind only when it holds them.
