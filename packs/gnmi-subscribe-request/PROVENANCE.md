`tools/gen/protobuf-4-run.sh`) with the envelope `gnmi.SubscribeRequest`. The schema files are not kept in this

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `gnmisubscriberequest`, the names file
`tools/gen/names/gnmi-subscribe-request.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no comment
and no line of a file. The values in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-4-vectors.py`).
