# Provenance of the schema sources

Pack `osi-motion-request` and module `osimotionrequest` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/osi-run.sh`) with the envelope `osi3.MotionRequest`. The schema files are not kept in this
repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `osimotionrequest`, the names file
`tools/gen/names/osi-motion-request.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file. No source file is copied, so no file of this repository is a
Covered Software file under MPL-2.0. The values in the vectors are made by the generator.
