## The message

`wire bits`, `bit_order lsb`, `word_bytes 1`; hex text. One SBP frame from the
preamble through the payload; all numbers are little-endian:

| Bytes | Content | In the pack |
|---|---|---|
| 0 | preamble 0x55 | common `when` |
| 1-2 | message type | per-kind `when` |
| 3-4 | sender id | `sbp.sender` (module `sbp`, shared by every SBP pack) |
| 5 | payload length in bytes | per-kind `when` = the message's fixed size |
| 6 … | payload | the kind's `field` lines, at their offsets |
| after the payload | CRC-16 (2 bytes) | not mapped |

The message is the frame without its CRC, in both directions: decode takes the
preamble, header and payload, and encode writes them. A framer adds the CRC
before sending and checks it on receipt: CRC-16 CCITT (polynomial 0x1021,
initial value 0) over the header and the payload, preamble excluded, written
little-endian after the payload. That is the item "Layered wires and framing"
of `docs/roadmap.md`. The fields of a payload follow one another with no
padding.

### Core keys

A key is bound only where the definition states the meaning and unit the
shared key holds; the unit is converted exactly by the transform:

- `lat`, `lon`: a double in degrees named `lat` / `lon` that the definition
  describes as latitude / longitude; `hae`: in such a message, the double
  `height` in metres described as height above the WGS84 ellipsoid.
- `track.vel_north_ms`, `track.vel_east_ms`, `track.vel_up_ms`: the signed
  32-bit `n`, `e`, `d` in mm/s described as the north, east and down velocity
  coordinates (up is the negative of down), or `v_up` in mm/s described as the
  vertical velocity, positive up.
- `course`, `speed_ms`: the unsigned 32-bit `cog` in microdegrees described as
  the course over ground from north, and `sog` in mm/s described as the speed
  over ground.

Accuracy fields (standard deviations) and covariances stay raw: `ce` and `le`
are error bounds of another kind. Times stay raw: an SBP time is a week number
and a time of week on the satellite time scale, which give an epoch time only
together and only with the leap-second offset to UTC.

### `requires`

Each kind requires up to 3 of its own keys, so an entity from another format
selects a kind only when it holds them.

## What is not mapped

- The CRC (see The message), and frames whose payload length is not the
  message's fixed size: such a frame selects no kind (`no-kind`).
- Enumerations and bit fields are carried as integers.

## Vectors

`vectors/rt-<type id>-<kind>.json`: one same-format round trip per kind, the frame
written by an SBP serializer in the generator from sample values (no CRC).

`vectors/x-*-to-geojson.json`: a frame (without its CRC) converted to GeoJSON;
the expected text is written by hand from the field values.
