## What this repository holds from those files

The generator is run with `--no-comments`. The pack, the module `foxglove`, the names file `tools/gen/names/foxglove-location-fixes.json` and
the generated vectors record field numbers, message and field names, enum value names and numbers,
and field types, and nothing else from those files: no comment and no line of a file. The values in the
vectors are made by the generator or written by hand (`tools/gen/protobuf-2-vectors.py`).
