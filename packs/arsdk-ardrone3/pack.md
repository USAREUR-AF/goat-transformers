# Pack: arsdk-ardrone3

The commands and events of the Parrot ARSDK feature `ardrone3` (id 1), one kind
per command. Public. Generated by `tools/gen/arsdk2pack.py` from `xml/ardrone3.xml` of
arsdk-xml (BSD-3-Clause, commit `2299c689be5951fa2104793e0154b0b5b1896c03`, sha256 `c9bfcfd9eae12b23dd2e5934b4e105f9fa4e08ad6c791bdc2d09a8fc2b5cb723`).

## Message convention

A message is one ARSDK command as libARCommands encodes it: the feature id (8 bits),
the class id (8 bits; a class of the project), the command id (16 bits), then the
arguments in schema order, little-endian. An enum is 32 bits, a bitfield is its base
integer, `float` and `double` are IEEE-754. The network framing around a command
(the ARNetworkAL frame: type, buffer id, sequence number and size) is not part of the
message; a caller removes it before `decode` and adds it after `encode`. The pack
selects the kind by the header (`when`); a command carries no length of its own, and
input beyond the last argument is not read.

Commands whose type is `LIST_ITEM` or `MAP_ITEM` are one item of a list each; each
item is one message, and the pack reads it as any other command.

## Shared keys

| Kind | Argument | Key | Transform | Absent when |
|---|---|---|---|---|
| `piloting_state_position_changed` | `latitude` | `lat` | `f64` | 500 |
| `piloting_state_position_changed` | `longitude` | `lon` | `f64` | 500 |
| `piloting_state_gps_location_changed` | `latitude` | `lat` | `f64` | 500 |
| `piloting_state_gps_location_changed` | `longitude` | `lon` | `f64` | 500 |
| `piloting_state_gps_location_changed` | `latitude_accuracy` | `track.sigma_north_m` | `sscale:1` | -1 |
| `piloting_state_gps_location_changed` | `longitude_accuracy` | `track.sigma_east_m` | `sscale:1` | -1 |
| `piloting_state_gps_location_changed` | `altitude_accuracy` | `track.sigma_up_m` | `sscale:1` | -1 |

- `piloting_state_position_changed`: the drone's position: latitude and longitude in decimal degrees, 500 when there is none (the sentinel, so the key is absent); the altitude is metres from the GPS with no stated reference, a raw key.
- `piloting_state_gps_location_changed`: the drone's location: latitude and longitude in decimal degrees, 500 when there is none; the three accuracies are one-standard-deviation errors in whole metres, -1 when there is none, north for latitude, east for longitude, up for altitude; the altitude is metres with no stated reference, a raw key.

The schema gives latitude and longitude in degrees from a GPS receiver but, apart from `controller_info` `gps_v2` (whose other altitude is above the WGS 84 ellipsoid), names no datum. The binding to `lat` and `lon`, which are WGS 84, rests on the reading that a GPS receiver reports WGS 84; a reviewer who does not accept it removes the entries of `BIND` in `tools/gen/arsdk2pack.py` and runs it again, and the raw keys, which stand on the same bits in every case, remain.

Other commands carry a latitude and longitude that are not the position of the reporting thing (a move target, a point of interest, a home, take-off or return location, a geofence centre, a followed target's trajectory): they are raw keys.

An entity from another format encodes as `piloting_state_position_changed` (it requires `lat` and `lon`); every other kind requires the raw `arsdkardrone3.feature_id`, which only a decoded ARSDK command holds.
