The generator is run with `--no-comments`. The pack, its module `apollodevkit`, the names file
`tools/gen/names/apollo-devkit.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file. The values in the vectors are made by the generator.
