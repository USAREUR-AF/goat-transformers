`schemas/input/csl-data.json` and nothing else. The file is not kept in this repository. Read on
2026-11-21.

## Licence

`LICENSE.txt` is the MIT License, "Copyright (c) 2007-2018 Citation Style Language and contributors". The
pack restates the schema's structure with keys of this project's naming and keeps the default Apache-2.0
label.

The vectors are generated by `tools/gen/jsonschema2pack.py` with values of its own and replayed through its
own JSON codec, written from spec/engine-spec.md; no engine is run.
