(run script `tools/gen/proto2pack-run.sh`) from the ten `.proto` files below. The
files are not kept in this repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, the module `takproto`, the
names file `tools/gen/names/cot-protobuf.json` and the generated vectors record
field numbers, message and field names, and field types, and nothing else from the
ten files. They contain no text from those files: no comment, and no line of a
file. The values in the vectors are made by the generator or written by hand.
