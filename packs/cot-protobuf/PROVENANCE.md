# Provenance of the schema sources

Pack `cot-protobuf` and module `takproto` are generated by `tools/gen/proto2pack.py`
(run script `tools/gen/proto2pack-run.sh`) from the ten `.proto` files below. The
files are not kept in this repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, the module `takproto`, the
names file `tools/gen/names/cot-protobuf.json` and the generated vectors record
field numbers, message and field names, and field types, and nothing else from the
ten files. They contain no text from those files: no comment, and no line of a
file. The values in the vectors are made by the generator or written by hand.

## Golden vectors: takproto

`packs/cot-protobuf/vectors/golden-pb-*.json` and `packs/cot-xml/vectors/golden-xml-*.json` are
written by `tools/gen/golden-takproto.py` from takproto, a reference TAK Protocol Version 1 codec,
not from this pack and not by any engine (shared-model hardening, item 2). takproto converts each
CoT XML event to a TakMessage and parses it back; the vector's expected output is takproto's message
and its model values are what takproto read.
