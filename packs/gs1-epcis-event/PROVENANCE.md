## Licence

The repository's `LICENSE` file is not a licence: it is GS1's disclaimer. It points to the GS1 IP Policy
(royalty-free or RAND licences to Necessary Claims, granted to GS1 members by the work-group
participants), advises implementers to check for patents, disclaims warranties, and names GS1 and its logo
as trademarks. Neither it, the README nor the schema files grant a copyright licence or carry a
"proprietary" notice; GitHub reports the licence as NOASSERTION.

So the source is public with no licence stated. Under this project's standing decision for such sources
the pack restates the schema's structure (member names, types, nesting, enumerations) with keys of this
project's naming, copies no text, and carries the label `LicenseRef-unstated` (REUSE.toml in this
directory, model/epcis.def.license). The patent position the disclaimer describes is a matter for the
operator.

The vectors are generated by `tools/gen/jsonschema2pack.py` with values of its own and replayed through
its own JSON codec, written from spec/engine-spec.md; no engine is run.
