# Pack: arsdk-common

The commands and events of the Parrot ARSDK feature `common` (id 0), one kind
per command. Public. Generated by `tools/gen/arsdk2pack.py` from `xml/common.xml` of
arsdk-xml (BSD-3-Clause, commit `2299c689be5951fa2104793e0154b0b5b1896c03`, sha256 `1e7c2bc23ecc285fe2b3f7093f0748e381d2bc019757e7b45f98d45118ea42d8`).

## Message convention

A message is one ARSDK command as libARCommands encodes it: the feature id (8 bits),
the class id (8 bits; a class of the project), the command id (16 bits), then the
arguments in schema order, little-endian. An enum is 32 bits, a bitfield is its base
integer, `float` and `double` are IEEE-754. The network framing around a command
(the ARNetworkAL frame: type, buffer id, sequence number and size) is not part of the
message; a caller removes it before `decode` and adds it after `encode`. The pack
selects the kind by the header (`when`); a command carries no length of its own, and
input beyond the last argument is not read.

Commands whose type is `LIST_ITEM` or `MAP_ITEM` are one item of a list each; each
item is one message, and the pack reads it as any other command.

## Shared keys

| Kind | Argument | Key | Transform | Absent when |
|---|---|---|---|---|
| `gps_controller_position_for_run` | `latitude` | `lat` | `f64` |  |
| `gps_controller_position_for_run` | `longitude` | `lon` | `f64` |  |

- `gps_controller_position_for_run`: the controller's latitude and longitude in decimal degrees, sent to the drone.

The schema gives latitude and longitude in degrees from a GPS receiver but, apart from `controller_info` `gps_v2` (whose other altitude is above the WGS 84 ellipsoid), names no datum. The binding to `lat` and `lon`, which are WGS 84, rests on the reading that a GPS receiver reports WGS 84; a reviewer who does not accept it removes the entries of `BIND` in `tools/gen/arsdk2pack.py` and runs it again, and the raw keys, which stand on the same bits in every case, remain.

Other commands carry a latitude and longitude that are not the position of the reporting thing (a move target, a point of interest, a home, take-off or return location, a geofence centre, a followed target's trajectory): they are raw keys.

An entity from another format encodes as `gps_controller_position_for_run` (it requires `lat` and `lon`); every other kind requires the raw `arsdkcommon.feature_id`, which only a decoded ARSDK command holds.
