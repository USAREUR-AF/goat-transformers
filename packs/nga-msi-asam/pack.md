# nga-msi-asam

NGA Maritime Safety Information, Anti-Shipping Activity Messages (ASAM): one record of the response of `/api/publications/asam`. Public. Generated by `tools/gen/nga-msi2pack.py` through `tools/gen/nga-msi-run.sh`; module `ngaasam` (`model/ngaasam.def`). Licence LicenseRef-NGA-MSI (PROVENANCE.md).

## Message convention

The endpoint answers one JSON object whose member `asam` is an array of records. A message of this pack is one element of that array: one JSON object, wire `json`. The caller takes the records out of the array; the envelope is not a message.

## Source

No API description was available: `https://msi.nga.mil/api` answered 503 on 2026-11-20 and no OpenAPI document of it is archived. The pack is built from 1 archived response(s) of the endpoint, 8897 record(s) in all (PROVENANCE.md lists them with their SHA-256). A member's type is the JSON type its non-null values have in those records.

## Shared-model keys

| Member | Key | Evidence |
|---|---|---|
| `latitude` | `lat` | degrees of latitude, WGS 84 (below) |
| `longitude` | `lon` | degrees of longitude, WGS 84 (below) |

Evidence. The archived responses give the members as JSON numbers with no unit or datum, so the binding rests on two things: NGA is the custodian of WGS 84 and publishes its maritime safety and charting products on it (the basis the maintainers accepted for this binding); and in every archived record (8897) the two numbers agree with the record's own degrees-minutes text to within one minute of arc, so the unit is decimal degrees, north and east positive.

Other members:

- `position` is the same position as degrees-minutes text, kept as a string; `date` is a calendar date with no time or zone, not bound to `time_ms`; `reference` names a report, not a moving entity, and is not bound to `uid`.

## Not mapped

- The response envelope and the query parameters of the endpoint.
- Types: a member whose real type differs from the archived one (an integer where the archive shows text) fails with `transform-decode`. The packs are as complete as the archived responses; an OpenAPI document of the API, when it is reachable, should replace this survey.
- Member values are carried as written: codes (`Y`, `N`, `U`, area letters) are not expanded.
