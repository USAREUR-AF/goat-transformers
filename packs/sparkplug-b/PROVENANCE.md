## What this repository holds from that file

The generator is run with `--no-comments`. The pack, the module `sparkplug`, the names file
`tools/gen/names/sparkplug-b.json` and the generated vectors record field numbers, message
and field names, and field types, and nothing else from the file: no comment and no line of
it. The values in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-public-vectors.py`).
