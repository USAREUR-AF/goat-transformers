## What this repository holds from those files

The generator is run with `--no-comments`. The pack, the module `opampservertoagent`, the names file `tools/gen/names/opamp-server-to-agent.json` and the generated vectors record field numbers, message and field names, enum value names and numbers, and field types, and nothing else from those files: no comment and no line of a file. The notes in pack.md (`tools/gen/notes/opamp.md`) are this repository's own words. The values in the vectors are made by the generator, which checks each one with its own protobuf codec.
