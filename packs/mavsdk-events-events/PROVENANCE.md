# Provenance of the schema sources

Pack `mavsdk-events-events` and module `mavsdkeventsevents` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/mavsdk-run.sh`) with the envelope `mavsdk.rpc.events.EventsResponse`, the message that the
plugin's `Subscribe…` call streams. The schema files are not kept in this repository.

## Licence

None was found. Checked at that commit: the repository has no licence, copying or notice
file (its 64 tracked files were listed); no `.proto` file carries a licence or copyright line;
`README.md` states no terms; GitHub's repository metadata names no licence. The one
mention of a licence in the repository is the package classifier of the code-generator
plugin `pb_plugins/setup.py`, which declares the trove classifier for a BSD licence for that
Python package; it names no BSD variant and does not cover the schema files. The parent
project github.com/mavlink/MAVSDK, which pins this commit as a submodule, is reported by GitHub
as `BSD-3-Clause`, but that licence file is in the parent repository and does not name the
submodule. The pack is therefore labelled `LicenseRef-unstated`
(`LICENSES/LicenseRef-unstated.txt`): commercial use unknown until the owner states terms.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `mavsdkeventsevents`, the names file
`tools/gen/names/mavsdk-events-events.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file. The values in the vectors are made by the generator. The notes
in `pack.md` are this repository's own words.
