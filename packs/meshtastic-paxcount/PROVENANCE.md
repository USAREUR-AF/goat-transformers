# Provenance of the schema sources

Pack `meshtastic-paxcount` and module `meshtasticpaxcount` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/protobuf-4-run.sh`) with the envelope `meshtastic.Paxcount`. The schema files are not kept in this
repository.

## License statements at that commit

`LICENSE` at the root of the repository is the text of the GNU General Public License, Version 3,
29 June 2007 (GPL-3.0); its first lines are `GNU GENERAL PUBLIC LICENSE` and `Version 3, 29 June
2007`. GitHub reports the repository as `GPL-3.0`. The thirteen `.proto` files carry no header:
none has a license line, a copyright line or a distribution statement. As for the packs
`meshtastic` and `cot-protobuf` (also GPL-3.0 sources), the generator takes names, field numbers
and types only.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `meshtasticpaxcount`, the names file
`tools/gen/names/meshtastic-paxcount.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no comment
and no line of a file. The values in the vectors are made by the generator or written by hand
(`tools/gen/protobuf-4-vectors.py`).
