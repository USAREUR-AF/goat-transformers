## The binary encoding

The encoding rules are those of OPC 10000-6 (OPC UA Part 6), version 1.05, section 5.2, read at
https://reference.opcfoundation.org/Core/Part6/v105/docs/5.2 on 2026-11-20. They are restated in
this repository's own words in `tools/gen/opcua2pack.py` and `pack.md`; no text or table of the
document is copied.

## What this repository holds from those files

DataType names, field names, field types, value ranks and the optional and union flags of each
structure, the supertype of each DataType, and the numeric NodeId of each Default Binary
encoding object. No description, documentation text or other content of the files. The values
in the generated vectors are made by the generator.
