# Provenance: nitf-image-subheader pack

Read on 2026-11-19. No source file is copied into this tree. The pack holds the
order, size and type of the fixed header fields, restated in this project's
words; the vectors hold headers written for this pack by
`tools/gen/nitf-header-vectors.py`.
