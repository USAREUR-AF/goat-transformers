Generated by `tools/gen/nga-msi2pack.py` through `tools/gen/nga-msi-run.sh`; module `ngalol` (`model/ngalol.def`). Licence LicenseRef-NGA-MSI (PROVENANCE.md).

## Message convention

The endpoint answers one JSON object whose member `ngalol` is an array of records. A message of this pack is one element of that array: one JSON object, wire `json`. The caller takes the records out of the array; the envelope is not a message.

## Source

No API description was available: `https://msi.nga.mil/api` answered 503 on 2026-11-20 and no OpenAPI document of it is archived. The pack is built from 4 archived response(s) of the endpoint, 5 record(s) in all (PROVENANCE.md lists them with their SHA-256). A member's type is the JSON type its non-null values have in those records.

## Shared-model keys

None bound. The responses name their members and show their JSON types but state no meaning, unit, datum or time base, and AGENTS.md binds a shared key only on a statement of the same meaning and unit. In particular:

- `position` is degrees-minutes-seconds text of two lines; `heightFeetMeters` holds two numbers in one text; they are strings.

## Not mapped

- Members null in every archived record show no type: `subregionHeading`, `localHeading`, `precedingNote`, `postNote`. A non-null value of one is residue: carried back into this format, not to another.
- The response envelope and the query parameters of the endpoint.
- Types: a member whose real type differs from the archived one (an integer where the archive shows text) fails with `transform-decode`. The packs are as complete as the archived responses; an OpenAPI document of the API, when it is reachable, should replace this survey.
- Member values are carried as written: codes (`Y`, `N`, `U`, area letters) are not expanded.
