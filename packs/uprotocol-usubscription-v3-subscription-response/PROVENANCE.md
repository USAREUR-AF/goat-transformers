# Provenance of the schema sources

Pack `uprotocol-usubscription-v3-subscription-response` and module `uprotocolusubscriptionv3subscriptionresponse` are generated by `tools/gen/proto2pack.py` (run script
`tools/gen/uprotocol-run.sh`) with the envelope `uprotocol.core.usubscription.v3.SubscriptionResponse`. The schema files are not kept in this
repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The pack, its module `uprotocolusubscriptionv3subscriptionresponse`, the names file
`tools/gen/names/uprotocol-usubscription-v3-subscription-response.json` and the generated vectors record field numbers, message and field
names, enum value names and numbers, and field types, and nothing else from those files: no
comment and no line of a file. The values in the vectors are made by the generator.
