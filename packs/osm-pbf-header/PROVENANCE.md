# Provenance of the schema sources

Packs `osm-pbf-blob-header`, `osm-pbf-header` and `osm-pbf-primitive` and their module `osmpbf` are
generated by `tools/gen/proto2pack.py` (run script `tools/gen/protobuf-2-run.sh`) from the two files
below. The files are not kept in this repository.

## What this repository holds from those files

The generator is run with `--no-comments`. The packs, the module `osmpbf`, the names files `tools/gen/names/osm-pbf-*.json` and
the generated vectors record field numbers, message and field names, enum value names and numbers,
and field types, and nothing else from those files: no comment and no line of a file. The values in the
vectors are made by the generator or written by hand (`tools/gen/protobuf-2-vectors.py`).
