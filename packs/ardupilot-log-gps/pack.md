# ardupilot-log-gps

ArduPilot DataFlash log message `GPS`, logged by every vehicle that builds the library, as the payload of one log
record. Generated by `tools/gen/aplog2pack.py` (run by `tools/gen/aplog2pack-run.sh`);
do not edit by hand.

## Message convention

A log record is a 3-byte header (0xA3, 0x95, the type id) and a payload. A message
of this format is the payload, 48 bytes. The type id of `GPS` is given by an FMT
record of the same log, and the payload holds no value that names the message, so
no `when` line could select it: each message is a format of its own and the caller
names it. The fields follow one another in the order of the format string `QBBIHBcLLeffffB`,
with no padding, little-endian, as the FMT record states them.

## Layout

| Offset (bytes) | Bits | Label | Format character | Line |
|---|---|---|---|---|
| 0 | 64 | `TimeUS` | Q, uint64, unit s, multiplier 1e-6 | `aplog.gps_timeus` uint |
| 8 | 8 | `I` | B, uint8, unit instance | `aplog.gps_i` uint |
| 9 | 8 | `Status` | B, uint8 | `aplog.gps_status` uint |
| 10 | 32 | `GMS` | I, uint32, unit s, multiplier 1e-3 | `aplog.gps_gms` uint |
| 14 | 16 | `GWk` | H, uint16 | `aplog.gps_gwk` uint |
| 16 | 8 | `NSats` | B, uint8, unit satellites, multiplier 1e0 | `aplog.gps_nsats` uint |
| 17 | 16 | `HDop` | c, int16, value times 100, multiplier 1e-2 | `aplog.gps_hdop` twos |
| 19 | 32 | `Lat` | L, int32 latitude or longitude, degrees times 10^7, unit deglatitude, multiplier 1e-7 | `lat` sscale:1/10000000 |
| 23 | 32 | `Lng` | L, int32 latitude or longitude, degrees times 10^7, unit deglongitude, multiplier 1e-7 | `lon` sscale:1/10000000 |
| 27 | 32 | `Alt` | e, int32, value times 100, unit m, multiplier 1e-2 | `aplog.gps_alt` twos |
| 31 | 32 | `Spd` | f, float32, unit m/s, multiplier 1e0 | `aplog.gps_spd` f32 |
| 35 | 32 | `GCrs` | f, float32, unit degheading, multiplier 1e0 | `aplog.gps_gcrs` f32 |
| 39 | 32 | `VZ` | f, float32, unit m/s, multiplier 1e0 | `aplog.gps_vz` f32 |
| 43 | 32 | `Yaw` | f, float32, unit degheading | `aplog.gps_yaw` f32 |
| 47 | 8 | `U` | B, uint8 | `aplog.gps_u` uint |

## Shared-model keys

| Label | Key | Evidence |
|---|---|---|
| `Lat` | `lat` | format character `L` ("int32_t latitude/longitude" in the format table of `libraries/AP_Logger/LogStructure.h`), unit `D` (deglatitude), multiplier `G` (1e-7): degrees times 10^7, decoded with `sscale:1/10000000`; the position a GNSS receiver reports for the vehicle |
| `Lng` | `lon` | format character `L` ("int32_t latitude/longitude" in the format table of `libraries/AP_Logger/LogStructure.h`), unit `U` (deglongitude), multiplier `G` (1e-7): degrees times 10^7, decoded with `sscale:1/10000000`; the position a GNSS receiver reports for the vehicle |

The log definition names no datum. The binding rests on the unit and the scale
above and takes the values as the WGS 84 latitude and longitude that `lat` and
`lon` hold; a log whose positions use another datum must not be read through it.
Altitudes are not bound: this family binds latitude and longitude only.

## Not mapped, and why

| What | Why |
|---|---|
| The 3-byte record header | it belongs to the log, not the message; the type id differs per log |
| Units and multipliers | they are stated in the key meanings of `model/aplog.def`; the raw keys keep the wire integer, as DataFlash readers before scaling do |
| Bytes of a text field after its first NUL | `ascii` removes trailing NULs and refuses other bytes outside 0x20-0x7E (`transform-decode`) |
| NaN and infinite floats | the `f32` and `f64` transforms refuse them on decode |
| FMT, FMTU, UNIT and MULT records | they describe the other records of a log and are not messages of this format |

## Vectors

`vectors/gen-rt.json` is a round trip with every field set: values chosen by the generator,
packed by its own serializer from the format string. Other `gen-*` files are edge and
error cases and conversions to geojson, each with its rule in `source`. 3 vector file(s).
`packs/geojson/vectors/gen-geojson-to-ardupilot-log-gps.json` converts from geojson.

The definition is in `libraries/AP_GPS/LogStructure.h`; see `PROVENANCE.md`.
